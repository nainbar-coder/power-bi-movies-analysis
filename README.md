# Cinema Industry Trends 2015–2025 - Power BI Dashboard

## Overview
This project analyzes trends in the cinema industry between 2015 and 2025, with a focus on the impact of the COVID-19 pandemic on movie releases, profitability, and industry performance.

## Tools Used
- Power BI

## Project Focus
- Comparing pre-pandemic, pandemic, and post-pandemic periods
- Reviewing movie count trends over time
- Examining profitability across different eras
- Presenting industry changes through interactive dashboard visuals

## Files Included
- Power BI dashboard screenshots / PDF export

## Key Skills Demonstrated
- Dashboard design
- Data storytelling
- Trend analysis
- Comparative analysis
- Visual communication
